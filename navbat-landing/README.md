# Navbat — Startup/SaaS landing sahifasi

Statik sayt: `index.html`, `style.css`, `script.js`. Hech qanday build yoki kutubxona kerak emas.

## Mahalliy ochish
`index.html` faylini brauzerda oching.

## Deploy qilish (bepul)
- **Netlify Drop:** https://app.netlify.com/drop sahifasiga shu papkani sudrab tashlang.
- **GitHub Pages:** fayllarni repoga yuklang -> Settings -> Pages -> Branch: main / root.
- **Vercel:** `vercel` buyrug‘i yoki papkani dashboard orqali yuklang.

## Obuna formasi
Hozir ma’lumotlar brauzerning `localStorage` ida saqlanadi (demo). Haqiqiy ishlatish uchun
`script.js` ichidagi izohli joyda `fetch()` bilan o‘z serveringiz yoki Formspree/Google Forms ga yuboring.
